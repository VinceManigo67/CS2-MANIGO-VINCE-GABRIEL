# Electricity calculator 

## Description
This program calculates your total electricity bill by multiplying your consumption with the rate.

## Version 1 – Original code without input validation
- Input: Accepts a customer name, and the previous and current reading
- Process: Calculates the consumption, multiplies it with the rate, then displays the total bill.
- Output - Total bill.
- Input validation: Name must not be empty, previous reading must be at least 0, and current reading must be at least the previous reading.
